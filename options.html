    How to get a Microsoft key
    1. Open Azure. First set the portal language to English: click ⚙ at the top right, open the language settings, choose English, and apply the change. The names below use English.
    2. Search for Translator and select Create.
    3. Choose your subscription and a resource group. If you create a resource group on a separate page, choose any available region there, such as East US. That setting is for the resource group.
    4. On the Translator creation page, choose Global for the Translator's Region if offered, or choose an available region. Set Pricing tier to Free F0. Enter a name, then select Review + create → Create.
    5. After it finishes, select Go to resource → Resource Management → Keys and Endpoint. Copy KEY 1 or KEY 2 into the key box above.

    The Azure account must have an active subscription. A new account may need phone and card checks. F0 has a monthly free amount; the account's trial period is separate. See the official guide.

    Use the region of the Translator resource that owns your key. Leave empty for Global; otherwise enter its code, such as eastus. The resource group's region does not go here.

    Uses Microsoft's international service and your key. Only the word and target language are sent. About this service
