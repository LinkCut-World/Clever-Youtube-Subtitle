# Dictionary test excerpts

`dictionary.json` contains small excerpts from the optional WikDict snapshot
`2_2026-06`, adapted with the rules now in `wikdict-sqlite.js`. They test parsing and word-card
behavior without downloading full packs. These test files are excluded from
installation ZIPs and do not install any dictionary.

Source: WikDict by Karl Bartel, Wiktionary contributors through DBnary.
